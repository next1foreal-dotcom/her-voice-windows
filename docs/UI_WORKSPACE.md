# HER Voice — 全介面重構

## 設計與資訊架構

這次重構整個語音工作區，不只替換 Orb：

- **桌面工作區**：左側導航、中央語音舞台、右側即時會話記錄。逐字稿獨立捲動，不因長回覆拉高整個工作區。
- **手機版**：精簡頂部導航，主要通話按鈕優先於對話靈感。會話內容從抽屜開啟；示範入口保留於頁腳。
- **完整視覺系統**：墨綠／暖白雙色外觀、統一字體層級、間距、圖示、輸入框與控制元件。無外部字體、CDN 或圖片請求。
- **設定分區**：回答接口、聲音模型、裝置偏好、服務資訊。保留原有 provider、裝置與音色表單 ID、控制器和回呼。
- **專注模式**：隱藏導航、逐字稿與對話靈感，保留通話控制、設定及模式切換。
- **對話靈感**：只將提示填入文字輸入，不自動開始連線或送出。

## 功能邊界

- `ui.js` 仍只負責顯示與呼叫既有 actions；未變更 `VoiceClient`、音訊模組、傳輸協定或推理後端。
- 主畫面逐字稿和會話抽屜都以 `textContent` 填入使用者／模型內容；不將文字解讀成 HTML。
- 會話記錄來自目前的 client snapshot。這不是新增跨工作階段的歷史資料庫，也不新增錄音儲存。
- 外觀在沒有明確偏好時跟隨作業系統；手動切換只在瀏覽器儲存 `her-voice-theme`。儲存被禁用時仍可操作。
- 示範模式明確標示不採集麥克風、不呼叫 API。真實模式則提示語音在本機處理、文字會傳送至所選模型。
- 保留 WebGL Orb、真實輸入／輸出音量反應、2D 降級、減少動態效果與頁面隱藏時停止動畫的行為。
- 正式運行仍無需前端建置；只修改原有三個 web 靜態檔，不需調整後端允許清單。

### 可選瀏覽器回歸

開發環境需有 Playwright 與相容 Chromium（不屬於正式使用依賴）。

```sh
node scripts/ui-smoke.mjs
```

可選環境變數：

- `UI_CHROMIUM`：自訂 Chromium 執行檔路徑。
- `UI_SCREENSHOT_DIR`：輸出狀態截圖與 `results.json`；未設定時只執行斷言。

腳本自動在隨機的 loopback port 啟動暫存伺服器，結束時關閉。`tests/fixtures/ui-driver.js` 只供該伺服器使用，不會加進正式介面或後端靜態檔允許清單。

瀏覽器回歸包括：

- 1440×900、390×844 的待命、聆聽、思考、回覆、暫停及四個設定分區。
- 開始／結束、文字提示、送出、暫停／繼續、打斷、字幕切換、記錄清除、深淺色及專注模式。
- 設定方向鍵／Home／End 導航、Esc 關閉與焦點返回；聲音按鈕直接進入播放裝置分區。
- 主要按鈕在初始 viewport 可見；可見啟用按鈕至少約 44×44px；主要寬度範圍無橫向頁面溢出。
- 長逐字稿保持獨立捲動；HTML 樣式的對話文字不產生元素。
- 320、701、768、1080、1081、1280、1920px 的響應式寬度檢查。
- 實際 `app.js` 與 provider 控制器初始化，使用攔截的本機 API 測試回應。

另已在 headless Chromium / 軟體 WebGL 下檢查深淺色、錯誤／示範提示、連線／打斷狀態、長字幕＋輸入框與展開音色匯入表單。主要文字對比度 ≥4.5:1，表單輸入邊界 ≥3:1。
