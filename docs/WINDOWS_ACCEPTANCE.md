# 0.4：在 RTX 4080 SUPER 上完成双后端验收

目标为原生 Windows x64、RTX 4080 SUPER 16 GB、64 GB RAM。当前开发环境没有 Windows、NVIDIA GPU、真实麦克风／扬声器或用户 DeepSeek 密钥。以下结果统一保留为“未测”，由目标机器实际运行后填写。

先验收 **Drama 3 主用**，再使用相同参考录音和问题验收 **Qwen3-TTS 0.6B Base 备用**。两者均须测试，不把其中一个成功视为另一个也成功；如果主用尚未通过，可手动切换备用继续定位公共管线问题。

## 环境记录

记录 Windows、Python、NVIDIA 驱动、CUDA Toolkit、MSVC、浏览器、麦克风／耳机型号、参考录音时长与语言，以及 `.runtime/pip-freeze-windows.txt`。用 `doctor.py --json` 查看 Python/GPU 条件；保留 Drama `runtime.json` 中的固定版本和 SHA-256。不要在共享记录中附上密钥或 `.env`。

```powershell
.\.venv-speech\Scripts\python.exe .\scripts\doctor.py --json
.\scripts\install-drama.ps1 -DryRun
.\.venv-speech\Scripts\python.exe .\scripts\download-models.py --backend qwen3
```

以上用于检查或显示计划。真正构建及下载按 [DEPENDENCIES.md](DEPENDENCIES.md) 与 [DRAMA_SETUP.md](DRAMA_SETUP.md) 执行。

## 调整顺序

先保留默认多语 small、Drama context 2048／cache 8／GPU 专家运算与 Qwen 0.6B Base，完成可用性测试。Drama 出现资源或构建问题时，可手动选择 Qwen 完成公共 ASR／API／界面链路检查，再单独诊断 native 后端。

每次只修改一类变量，例如参考录音、ASR 模型或一个 Drama 资源参数。保留固定版本、相同输入和上述验收项目，不同时升级上游、模型和 CUDA 后再推断原因。任何目标硬件上的速度、中文质量或 16 GB 适配结论，都应附实际记录。
